# Tiny Form

Tiny Form is a lightweight Next.js app for building and publishing no-code forms quickly.

## Key Features

- Build forms with text, email, dropdown, and message fields
- Publish forms and share a public form link
- View and manage form submissions in a simple dashboard

## Available Pages

- `/` — Landing page
- `/builder` — Form builder interface
- `/dashboard` — Submission dashboard
- `/form/[slug]` — Public form view

## Tech Stack

- Next.js 16
- Tailwind CSS 4
- Prisma
